刷机前请先读完这一页。

1. 只适用于系统版本为 B16 的中兴 U30 Air / F50 一类设备。版本不对不要刷。
2. 任何写入操作之前，先做一次分区备份。
3. 推荐使用本仓库自带的 Magisk 28103，不要自行下载其它版本，否则可能破坏「禁止系统更新」相关补丁。
4. 刷完后如果只是想禁用 OTA，可以不装 Magisk App；需要模块管理或装 UFI-TOOLS 时再装。

名词说明
  直接插电：先运行脚本，设备保持关机，再插入数据线。
  短接模式：先运行脚本，设备关机后短接调试点的同时插线；看到进度后再松开。

常见报错
  kick reboot timeout
    → 改用短接模式脚本继续，一般不必拔线、也不必关掉脚本。

  wrong command or wrong mode detected
    → 同时按电源键 + 音量上键 7–10 秒强制重启，再试短接或备用脚本。

手动 Root（出现 FDL2 > 时逐行输入）
  path .\bin
  w trustos .\bin\tos.bin
  w boot .\bin\magisk.img
  reset

重要提醒
  刷错版本常见现象：Wi‑Fi 5 变成 Wi‑Fi 4。出现后说明系统和 Root 包版本不匹配。
  Magisk 安装后若提示修复，请用本仓库 packages 目录里的 Magisk 28103 完成，不要换别的版本。
